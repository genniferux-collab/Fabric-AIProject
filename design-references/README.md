# 设计参考与溯源资料（非交付件）

此目录与 `preview/` 同级，仅供设计对照、来源追溯和后续组件/skill 研究，不参与应用运行、构建或离线导出，不包含在页面交付包中。历史说明记录其编写时的状态；当前实现以 `preview/src/` 为准。

- `site-tips/`：Pixso 站点提示的规格、节点清单、原稿截图、动效分析与参考原件。
- `uc2-report-v2/`：黄金基线报告的原稿来源与历史内容记录。

页面实际使用的图标与 GIF 已放在 `preview/assets/uploads/pixso-site-tips/`，组件从 `assets` 引用。此处保留的同名 SVG/GIF 是设计归档原件；运行时不引用此目录。后续新增页面素材统一放入 `preview/assets/`，不要把参考截图当成运行依赖。
