# Fabric 站点状态实现与复用入口

- 任务提示：`preview/src/components/site-task-tip/`。单条212×56，最小高40；多条用68×40的AI图标与数字聚合，不同时铺开多张事件气泡。
- 地图交互：`preview/src/components/map-network-overlay/`。站点上方持续显示处置状态；嘉定左错位、外高桥右错位，优先贴近站点。布局支持缩放、不同气泡宽高，并避让节点、名称和其他气泡。
- DC基本信息只由用户悬浮或聚焦站点触发，优先显示在站点右侧，不自动轮播。聚合数字打开的是事件列表，与DC基本信息卡分开。
- 事件集合取自统一账本`preview/src/mock/task-registry.js`，首页、地图、UC1–UC4使用同一任务ID与状态。演示关注区通常显示20条：待接管1，处置中4–6，其余已完成；真实任务状态优先，不靠修改标签伪造数量。
- 唯一演示时钟位于`preview/src/hooks/use-network-tasks.js`，变化间隔8–12秒。普通进度更新不改变排序时间，实际UC阶段按原流程回写。
- 左侧新事件300ms轻淡入，局部位置变化220ms，无弹性；右侧气泡300ms淡入，不做缩放弹跳。滚动、切标签和技能折叠时不执行列表位置补偿；支持减少动态效果设置。
- 用户提供的原始GIF在`animations/site-ai-processing.gif`，原件未裁剪或重绘。其有效图形约占画布41.58%；当前完整图元素168px，可见动效约70px，中心遮罩保护建筑图标，偏向底座下层。仅实际运行的站点显示，暂停或无运行任务时移除。

图标与视觉规格来自本目录README和manifest列明的Pixso节点。本资料包用于后续组件或skill生成，不代表已安装新的skill，也不包含生产网络后台接入。
