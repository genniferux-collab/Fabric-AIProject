此目录是后续组件/skill 的参考资料包，尚未生成或安装新 skill。图标均由 Pixso 原件导出为 SVG，保持 16×16 viewBox，未用相似图标替换。

## 结构规则

- 容器宽 212px；原稿双行实例高 56px。本次用户明确要求最小高度 40px，单行内容也保留这个下限。
- 内边距上/下 8px、左/右 12px；图标 16px；图文间距 12px；文本宽 160px，字号/行高 12/20px；圆角 12px。
- 进行中环 26px，围绕固定 16px 图标运动，不让文本跟随抖动。
- 内容采用“数据中心 + 任务对象/名称 + 执行状态”。状态改变由同一任务记录驱动，避免提示与首页统计各自模拟。

## 按图标样式命名

统一名称：`tips/{icon-family}/{business-state}/{theme}/{interaction}`。图标文件不重复存储深浅主题；主题变化由容器与文字完成。`manifest.json` 保存每个图标的源节点和颜色。

| SVG 文件 | 图标/颜色 | 推荐业务用途 |
|---|---|---|
| `manual-decision-orange.svg` | 人工决策 / `#F4840C` | 需要人工接管或作出决策 |
| `repair-attention-red.svg` | 修复 / `#E7434A` | 修复相关待处置项 |
| `repair-running-blue.svg` | 修复 / `#2070F3` | 修复执行中 |
| `repair-completed-green.svg` | 修复 / `#36C18D` | 修复动作完成 |
| `ai-attention-red.svg` | AI / `#E7434A` | AI 任务需要关注 |
| `ai-running.svg` | AI / `#2070F3` | 检查、挖掘、生成进行中 |
| `ai-completed-green.svg` | AI / `#36C18D` | AI 任务已完成 |
| `timer-running-cyan.svg` | 计时 / `#009DFF` | 周期、计时、历史提示 |
| `completed.svg` | 圆形勾 / `#36C18D` | 完成，或完成后待审阅 |

每种图标可与 `dark/light × default/hover` 容器组合，共 36 种静态表现。运行态再组合进度环，完成态组合完成关键帧；不需要把每种组合重复导出为图片。

## 动效储备

源稿提供进行中环的两个关键帧，以及“带外环勾 → 普通勾”的完成关键帧。建议实现为：

1. 进行中：机器人保持稳定，仅外环连续旋转；可用约 1600ms 线性循环。
2. 完成：替换为绿色勾，外环柔和收束或淡出，建议约 600ms。
3. 减少动态效果设置下停止连续旋转，保留图标与明确的状态文本。

上述时长是实现建议，未从 Pixso 读取到明确的时间标注；几何、颜色与关键帧样式有源稿依据。

## 语义边界

- 执行状态、合规结论、规则审阅是三个独立维度。发现不合规仍可表示“检查任务完成”，不能误标为执行失败。
- 黄金基线挖掘完成后可以“待审阅”；未审阅的候选规则不等于已经采用的正式基线。
- “完成”图标不表示所有告警消失，也不代替修复后的验证结论。
- 任务条数、规则条数、设备台数单独存储，不相加作为任务总数。
- 所有状态均有文字，不只依赖红/蓝/绿的区分。
