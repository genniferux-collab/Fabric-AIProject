# 等值 rem 迁移规则

本轮按既有 16px 根字号迁移，保持当前 PC 视觉、容器布局与业务交互。

## 基准

- 当前页面由 `src/views/stage/index.css` 的 `html:has(.stage-viewport){font-size:16px}` 维持根字号；此规则在迁移前已经存在，本轮保留。
- `assets/style/base.css` 虽包含 12/14/16/20px 的响应式根字号预设，本页面继续由原 stage 规则覆盖，不通过改变根字号实现整页缩放。
- 1920×1080、1440×900、1366×768、2560×1440 的迁移前后实测根字号均为 16px。
- 换算：`rem = 原 px / 16`，如 14px → 0.875rem、24px → 1.5rem、12px → 0.75rem。

## 已迁移

CSS 中的字号、字体简写中的字号/行高、带 px 的行高、字距、内外边距、行列间距、滚动留白、圆角；静态 JSX style 中适用的间距值。55 个源码文件、3972 处声明发生等值转换。

无单位行高如 1.5 保留，不将其误当 px。CSS 变量、百分比与已有 rem 按原样保留。设计颜色 token 不变。

## 保留 px

- 根字号基准、1px 边框、描边与焦点轮廓；
- 现有宽高、结构定位、地图与拓扑坐标、原始素材尺寸；
- 现有媒体查询/容器查询断点、栅格约束和独立的响应式布局；
- 阴影、模糊、位移以及其他需要维持当前几何的绘制参数。

不对 SVG/PNG/GIF、地图素材或运行时坐标数据进行全局替换。

## 验证

- 原项目构建及 UC2/UC4 数据模型验证通过。
- 四种 PC 尺寸、22 组页面状态：包含首页、统一任务侧栏、AI 欢迎页、模板选择；前三种尺寸额外验证 UC2/UC4 报告。
- 固定演示数据及时间，等待有限动效与 ResizeObserver 完成，统一滚动位置后，对照 21078 个节点状态的字号、行高、字距、内外边距、gap、圆角、边界矩形与滚动范围：未发现差异。
- 保留上述固定几何声明与断点的源码对照通过。

以上为 Chromium 下、已测窗口与状态的验证结果，不代表所有浏览器或任意根字号均已验证。

## 后续维护

新增文字、间距、圆角优先沿用等值 rem 或现有设计 token；边框、坐标、素材和断点按用途保留 px。继续编辑 app.jsx/src/assets 后构建 index.page.html，不直接修改生成 HTML。1920×1080 的外层 PC 预览仍由 site-preview.html 等比呈现，应用内的响应式规则独立运行。

## 后续侧栏自适应

rem 与 ict-react-coder 在 1920 设计基准一致；本项目有意保留固定 16px 根字号，未使用基础样式的 12/14/16/20px 分档缩放，也尚未把所有字面 rem 转成语义间距/字号 token。

首页、欢迎页与 UC1–4 事件详情共用独立响应式宽度：1920×1080 保持592px，以可用窗口宽度约31.62%和高度约52%取较大值，限制在360px至720px，同时上限不超过可用宽度一半（极窄窗口由最小可读宽度优先）。窄侧栏采用容器查询调整内部排版；不改变根字号和地图自身投影。侧栏宽度统一由 stage/desktop.css 的 --agent-panel-width 定义，内容页不再声明另一套宽度；画布左侧偏移同步读取 --agent-width。

原文中等值迁移的零差异验证属于 rem 迁移步骤；后续侧栏自适应是用户授权的独立布局调整，按对应断点验收。

## 欢迎页与 UC 画布的独立适配

- 欢迎页在标题栏、底部固定输入区之间居中；空间不足时仅欢迎内容滚动。592px 侧栏保持472px内容宽度，较宽侧栏可增长至640px；窄侧栏按容器查询减少侧边留白。输入框填充侧栏的可用宽度。
- UC1 的列表随窗口高度分配空间，来源卡片按容器宽度换列，筛选和分页保留在各自模块。
- UC2 挖掘图谱保持设计素材坐标和路径比例，屏幕文字保持可读；窄画板仅图谱内部横向滚动，不压扁图形。摘要按站点锚点避让，单规则详情在窄面板聚焦显示；每个图谱实例的 SVG defs 标识独立。
- UC3 保留流程图缩放/适应宽度/重置与局部滚动，规则表单按真实可用宽度重排。
- UC4 拓扑、映射使用局部滚动保持阅读尺寸，报告摘要、卡片、工具栏按容器宽度重排，表格自身横向滚动。
- 以上适配不依赖修改根字号，不更改业务数据、候选规则采纳原则或画布内部页签的框架。

验收证据保存在工作区 outputs 中：欢迎页布局修复-验证.json、UC1-UC3画布适配-验证.json、UC2挖掘适配-验证.json、UC4适配-验证.json。除原有默认1920×1080预览，site-preview.html 支持手选“铺满窗口”；viewport=fill 仅用于显式查看自适应效果，不改变默认PC预览规则。

侧栏一致性检查：验证欢迎页进入 UC1–4 后宽度不变，并覆盖首页事件入口、重设窗口、UC2 单规则抽屉与内部画布页签，输入框持续填满可用宽度。欢迎内容仍在可用区域内居中，事件对话保持从上向下阅读，两者的内容对齐按各自用途保留。


## 2026-10-31：rem 与 token 补齐

本节是对上文首轮迁移边界的补充，继续采用固定 16px 根字号；不通过根字号分档缩放应用，不修改既有媒体/容器断点。

### 源码约定

- 非根字号的普通 CSS 字号已补齐 rem；与 skill 刻度相同的字号、间距、字重、圆角引用现有 token。不匹配的特殊设计值继续使用等值 rem，避免把不同数值强制归并。
- 字号与行高分别维护：例如既有 14px/22px 保留为字号 token + 1.375rem，不整体替换成 14px/21px 的字体角色简写。
- 本项目 `assets/style/base.css` 的 2/4/6/8/12px 圆角刻度改成 .125/.25/.375/.5/.75rem；语义圆角别名继续引用它们。圆形/胶囊使用的 50% 与 9999px 保留。没有修改已安装 ict-coder 的资源文件。
- 普通按钮、输入框、分页、图标、欢迎页与首页指标控件的尺寸按完整组合等值转换，包括 48px 输入框、32px 发送按钮及 8px 内缩。素材 sprite 的内部裁切尺寸、地图/图谱坐标、背景纹理、描边和运动绘制参数保留原值。
- HTML 图片的 rem 显示尺寸写入 CSS/style；不把 rem 字符串写入 HTML img 的 width/height 属性。SVG 的 viewBox 与内部 image 坐标不变。
- 保持 48px 顶栏/导航轨、侧栏比例 clamp、关联画布偏移与断点；这些是布局策略，不混入本轮单位整理。

### 浏览器与绘图库边界

- `src/lib/css-length.js` 统一将 px/rem/em、var/calc/clamp 解析为绘图库所需的未缩放 CSS px。字符串长度交给 CSS 引擎解析，不用 parseFloat 截取表达式。
- ECharts 使用容器的 clientWidth/clientHeight；根字号或主题/token 变化时重新绘制现有实例。每个 document 共用一个不可见 1rem 探针，最后一个订阅卸载时清理，不使用轮询。
- `responsive-beam` 从实际卡片读取圆角后传给只接受数字的光效库，避免卡片与光效的圆角分别维护。
- UC2 环形图继续保持半透明环内侧 .5rem 圆角、外侧直角；精确相切路径未改，当前根字号下绘制半径为 8px。
- 表格普通列宽使用 rem；scroll.x 等数值 API 通过统一函数换算。表体空间优先测量真实表头/分页及 token 留白，避免外层预览 transform 影响 getBoundingClientRect。最终 scroll.y 仍为实际测量的 px。
