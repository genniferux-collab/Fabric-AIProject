# 画布基础交互规则

- 画布右上角的“新开页签”按钮通过共享 ArtifactOpen 组件打开当前画布。
- 页签添加到当前页面的画布页签栏，保留顶部导航和左侧 AI 对话；不打开浏览器页签、窗口或新页面。
- 新页签完整、独立展示被点击的单个画布，不替换为规则列表或其他内容。
- 打开或切换独立画布页签时恢复左右布局：退出此前的放大画布状态，确保左侧 AI 对话可见。全屏放大仅由“放大画布”按钮主动触发。
- 切换全景画布和独立页签时保留画布筛选、交互状态及各页签滚动位置。
- 同一画布已有独立页签时激活原页签，避免重复；关闭后可从全景重新打开。
- 查看全部规则、单规则详情和规则编辑属于内容操作，与画布新开页签入口分开。

UC1 检查规则、UC2 网络拓扑、黄金基线挖掘、黄金基线报告、UC3 检查规则图谱及 UC4 设备概览、规则匹配、报告沿用同一页签容器与 openArtifact 行为。

UC2 各模块右上角操作均使用 ArtifactOpen：`uc2-topology`、`uc2-mining`、`uc2-report`。只允许画布外层工具栏的“放大画布”按钮改变全屏状态，模块内部禁止调用 setFull。意图分析仅为生成加载态，目前没有另开页签按钮。

## UC1–UC4 本轮统一原则（2026-10-29）

- 1B：任务全部自动执行，移除演示用暂停/下一步；重播不暂停任务。
- 2A：步骤按可折叠思考、分析结论依次呈现，结论停留后进入下一步。
- 3A：对应画布可用后显示定位入口。
- 4B：筛选保持单选，重复点击仍选中；通过全部入口恢复。
- 5A：列表共用 UC4 形式的页码、上下页、每页条数。
- 6A：详情通过页签返回，不再重复放置返回报告按钮。
- 7A：规则编辑显式保存/取消，固定底部操作栏，提交校验并回显保存结果。
- 8A：用户上滑停止自动跟随，通过“回到最新内容”恢复；不因阶段切换抢回阅读位置。
- 9B：保留各业务结果卡片的信息排布。
- 10A：UC1 查询列表移除无后续操作的复选框。

首页事件区：下滚先收起技能卡片并上移待您关注，收起后固定标题和 Tab，仅事件卡片继续滚动；回到列表顶部再上滑时恢复技能卡片。

首页事件与站点映射卡片的内部光晕仅触发一次，约 1 秒内淡出；持续悬浮不保持彩色发光。分页器的每页条数、箭头、页码和总页数必须保持单行对齐。


## 悬浮导航与扫描统一

- 首页左侧导航依据 Pixso 146:146740 / 146:146900：收起 48px、展开 250px，菜单高 48px。悬浮展开、移出收起；底部按钮支持键盘展开/收起，Escape 和点击外部收起。展开覆盖页面，不挤动工作区。
- UC2 网络拓扑扫描与 UC4 共用 RegionSweep，复用多色渐变、点阵拖尾和扫描时间进度；不再单独使用蓝色硬边扫描条。
